# Sprout five-agent demo v2
All startup amounts, people, capacity, goals and dates are **synthetic**. Currency: USD integer cents. Starting cash USD 300; proposed USD 400 spending has a USD 100 shortfall. No sales or expenses are fabricated as real outcomes. Catalog/goal/campaign references use the existing validated v1 snapshot schema.

Import JSON/CSV through the existing demo preview/commit. Use CEO, Finance, Marketing, Operations and Strategy in the shared workflow; HR records from earlier releases remain accessible. The legacy deterministic launch simulator has its own HR review and is a separate retained demonstration.

Brand and operating references are provided for authorized RAG indexing. No social account, real hiring, email or paid campaign is performed. The shared launch uses four zero-cost internal brief tasks and existing owner approvals. See docs/SHARED_AGENT_WORKFLOW.md for the full sequence.
