## Reproduce

Build the images described in NEXT_RELEASE_RUNBOOK.md (API/Support PRELOAD_MODELS=0 for this profile, minimal worker, Next and Next Caddy), then:

```bash
python scripts/smoke_next_release.py --evaluation-output /tmp/fyp-evaluation.json
```

The script forces provider keys empty, uses fresh isolated volumes, does not start Caddy/ACME, exercises the ten private services and removes only its own test resources. `--components` cannot be combined with evaluation and never counts as full-topology acceptance. Never point this test at production volumes. Environment-specific proxy/CA setup may be required; TLS verification must remain enabled.
